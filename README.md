# Vue + GoA Design System Example

This project is a working example of using the
[GoA Design System UI Components](https://github.com/GovAlta/ui-components/)
in a Vue 3 application built with Vite and TypeScript.

Use this repository as a reference for:

- integrating GoA web components in Vue
- local development and testing of component usage
- experimenting with layout and styling using GoA components

## Prerequisites

- Node.js 18+ (recommended)
- npm

## Getting Started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
